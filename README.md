## Project Description

A 4-bit binary adder/subtractor designed using 74HC283 and 74HC86 ICs in Tinkercad.

### Operations
MODE = 0 → Addition
MODE = 1 → Subtraction

### Test Results
0011 + 0010 = 0101
0101 - 0011 = 0010
1111 + 0001 = 0000 with carry
